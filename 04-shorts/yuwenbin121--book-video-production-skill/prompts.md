# Example prompts

## 从书名开始

```text
使用 $book-video-production，为《活着》制作一条 30 秒、9:16、发布到抖音的中文图书介绍视频。采用高级文学风格，画面克制，配轻缓音乐，并生成独立封面。
```

## 使用参考视频

```text
使用 $book-video-production，先拆解我提供的 MP4，再为《百年孤独》制作同类节奏的视频。保留结构与字幕逻辑，但重新设计画面、字体和旁白，不复制原作者的素材或表达。
```

## 只做前期

```text
使用 $book-video-production，为《月亮与六便士》完成事实底稿、30 秒旁白、时间戳分镜和素材计划，先不要生成图片或渲染视频。
```

## 批量模板

```text
使用 $book-video-production 和 Remotion，建立可替换书名、作者、旁白、字幕、图片和音乐的竖屏图书视频模板。
```
