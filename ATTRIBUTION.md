# ATTRIBUTION · Créditos y licencias

Este repositorio agrega proyectos de terceros bajo **sus propias licencias**. IMPULSO IA no reclama ninguna propiedad sobre ese código ni modifica su contenido: cada repo se integró mediante clon superficial (`--depth 1`) y lo único que se eliminó fue el historial `.git` de cada clon. El contenido de cada carpeta es idéntico al del proyecto original en su último commit público, y su `LICENSE` se conserva dentro de la carpeta.

La columna **Licencia** refleja lo que reporta la API de GitHub en el momento del clonado: `—` = el repo no declara licencia; `NOASSERTION` = licencia personalizada que GitHub no mapea a un SPDX estándar. En ambos casos, revisa el archivo de licencia dentro de la carpeta local antes de reutilizar el proyecto.
